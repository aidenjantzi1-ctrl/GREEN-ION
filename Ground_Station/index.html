Motor-free bench recording and Wi-Fi disconnect check

Remove the motor and igniter. Keep the rocket stationary. This creates a separate TESTnnn.BIN RKT4 file and stops automatically within two minutes. It never controls ignition or deployment.

No live bench recording evidence.
  1. Start the test and note its TESTnnn.BIN file.
  2. Physically disconnect Windows from Feather Wi-Fi for 10–20 seconds. This action is not measured automatically.
  3. Reconnect. Check the reported recorder/file state; stop the test if still active, or wait for its two-minute automatic limit.
  4. Select Download and verify test. Inspect RKT4 records, duration, warnings and gaps; the original SD file and imported raw copy are retained. Analysis offers exports.
A simulated link loss is software evidence only. A real disconnect and uninterrupted SD recording remain NOT TESTED until physically performed.
