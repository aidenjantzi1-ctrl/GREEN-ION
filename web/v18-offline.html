CheckResultNext action / evidence

PASS means this specific software check had direct evidence, not that hardware is flight-ready. FAIL means a checked requirement was not met. NOT TESTED means evidence is absent or a real-device/manual check is required.

To test BIN import, use Data → Manual BIN import with an existing original file; inspect analysis and export an unchanged original. To test receiver, use Recovery → CONNECT RECEIVER and select the physical Uno in Chrome/Edge; verify valid, invalid and stale packets, then unplug/reconnect. Test offline restart only after cache registration by disconnecting the network and reopening the local app; the Feather bridge itself may be unavailable offline.

Physical microSD write/read/verify/temp-delete, barometer/IMU accuracy, GPS/LoRa RF, wake timing, Wi-Fi interruption and two sequential saved hardware flights remain NOT TESTED until performed with real equipment and separately recorded evidence. Never delete original flight files.
